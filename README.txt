ASCB: Math for IT
Files
  index.html   the page (text and structure)
  style.css    all the design and colors
  script.js    the tools, log in / create account, and quizzes
  quizzes.json the quiz questions (edit this to change the quizzes)
  images/      the three team photos

How to open
  1. In Visual Studio Code: File > Open Folder, choose this folder.
  2. Install the "Live Server" extension, then right-click index.html
     and choose "Open with Live Server".
  Note: the quizzes load quizzes.json, so open the site with Live Server.
  Double-clicking index.html will show the page but the quizzes will not appear.
